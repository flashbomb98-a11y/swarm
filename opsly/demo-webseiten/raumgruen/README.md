# RAUMGRÜN — Opsly Webseiten-Schnellstart Muster 01

Eine vollständig eigenständige, responsive **HTML-Demoseite** für den **fiktiven** Gartenpflegebetrieb „RAUMGRÜN“.

## Verwendung
- [index.html](index.html) speichern und lokal im Browser öffnen. Keine externen Bilder, Webfonts oder weiteren Dateien notwendig.
- Enthält Hero, drei Leistungsbereiche, Ablauf, Kontaktformular-Vorschau und responsive Navigation.
- Das Kontaktformular sendet **keine** Nachrichten und speichert **keine** Anfragen auf einem Server.
- Als sichtbarer Demo-Prototyp für den Opsly-Service **„einseitige kleine Firmenwebseite“** gedacht, nicht als kommerzielle Kundenreferenz.

## Vor Veröffentlichung für einen echten Kunden
1. Echtes Branding, korrekte Leistungen, Texte, Kontakt, Gebiet und Bildrechte klären.
2. Voll funktionsfähiges Kontaktziel nur mit Kundengenehmigung und Datenschutzprüfung integrieren.
3. Impressum, Datenschutzhinweise und notwendige rechtliche Informationen vom Kunden bereitstellen und überprüfen lassen.
4. Mobilgeräte, Barrierefreiheit, alle Links und Übermittlung nochmals testen.
5. Umfang, eine Korrekturrunde, Abnahme, Hosting und Zahlung schriftlich vereinbaren.
